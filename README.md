# 🏦 Loan Origination — Business Analysis Case Study

> **A self-directed Business Analysis case study focused on analysing and redesigning a loan origination process to improve efficiency, reduce manual intervention, and create a clearer digital workflow.**

---

## 📌 Project Overview

This project simulates a **Business Analysis engagement for a loan origination process**.

The objective was to analyse the existing **AS-IS process**, identify operational inefficiencies and manual activities, and design a proposed **TO-BE process** with documented business and functional requirements.

The project demonstrates how a Business Analyst can move from:

**Business Problem → Process Analysis → Requirements → User Stories → Process Improvement → Business Recommendations**

---

## 🎯 Business Problem

The existing loan origination process contains multiple manual activities, including:

- Repeated data entry
- Manual verification activities
- Multiple approval stages
- Manual document handling
- Limited process visibility
- Opportunities for improved workflow automation

These activities can contribute to longer processing times and increased operational effort.

The objective of the proposed solution is to create a more streamlined and digitally enabled loan origination workflow.

---

## 🔍 AS-IS Process Analysis

The existing process was analysed to understand:

- Current process steps
- Stakeholder involvement
- Manual activities
- Verification stages
- Approval gates
- Potential bottlenecks
- Opportunities for automation

The AS-IS analysis was then used as the foundation for designing the proposed TO-BE process.

---

## 🔄 TO-BE Process

The proposed process focuses on:

- Reduced manual data entry
- Integrated verification
- Streamlined approval workflow
- Exception-based handling
- Improved process visibility
- Greater digital automation

The TO-BE workflow represents a proposed future-state process rather than an implemented production system.

## 📝 Example User Story

**User Story**

> As a loan applicant, I want to submit my application and required information digitally so that I can avoid repeatedly providing the same information during the loan process.

**Acceptance Criteria**

- Applicant can enter required information digitally.
- Required fields are validated.
- Supporting documents can be submitted.
- Submitted information is available to authorized users.
- Applicant receives confirmation after successful submission.
